COMPILATION INSTRUCTIONS
------------------------

This package contains the LaTeX source for the manuscript. To compile:

1. Ensure you have a standard LaTeX distribution (TeX Live, MiKTeX, etc.)
2. Required packages: natbib, graphicx, tikz, float, subcaption, adjustbox,
   booktabs, longtable, amsmath, hyperref, geometry, setspace

3. Compile sequence:
   pdflatex main.tex
   bibtex main
   pdflatex main.tex
